## Completed (implemented, compiled, automated tests where applicable)

**Structure and Android**
- Permanent `android/` project (no longer regenerated by CI); app ID and
  namespace `com.aduchat.chat_adunka`; app name AduChat; adaptive icon,
  notification icon, splash (Android 12+ and older); minSdk 23;
  permissions for network, notifications, camera, microphone, Bluetooth
  audio and contacts; release signing from git-ignored `key.properties`;
  version from `pubspec.yaml` (2.0.0+3).

**User interface**
- Splash, welcome (original text kept), registration, login, OTP,
  profile setup, chats, contacts, conversation, group conversation, calls,
  settings, notification settings, privacy settings, account management,
  help and support.
- Light, dark and system themes. English, Somali and Arabic with
  right-to-left layout. Loading, empty and error states everywhere.

**Registration**
- Country picker and phone validation (E.164), SMS OTP with resend and
  auto-read, email/password sign-in for testing, password reset (account
  recovery), logout, unique usernames (atomic claim, enforced by the rules),
  profile photo, account deletion (with recent-login check).

**Contacts and directory**
- Search by username, name, or exact phone number; opt-in contact
  discovery that never uploads the address book; profile view; block,
  unblock and report; privacy switches for phone lookup, appearing in
  search, last seen and read receipts. Phone numbers are not readable in
  public profiles.

**Messaging**
- Real-time text, timestamps, ordering, sent/delivered/read status,
  typing indicator, online/last seen, offline queue, pagination, in-chat
  search, edit (48 h), delete for me or everyone, reply, forward, emoji
  panel, photos and voice messages (free, stored inline), videos and
  documents (Cloud Storage, when enabled), upload progress, retry of
  failed messages, duplicate prevention (client-side message ids),
  members-only attachment access.

**Groups**
- Create, name, picture, description, add/remove members, admins,
  "only admins can send", "only admins can edit info", leave (admin
  hand-over), delete (admins), system messages, read status, membership
  enforced by the rules.

**Calls (WebRTC)**
- One-to-one voice and video, incoming and outgoing screens, accept,
  decline, end, mute, speaker/earpiece, camera on/off, switch camera,
  duration, call history, missed calls, connection status, ICE restart on
  network changes, busy handling, permission prompts, Firestore signaling,
  free STUN, configurable TURN.

**Notifications**
- Permission request, FCM token management (saved privately, removed on
  sign-out), foreground and background local notifications for new
  messages and missed calls while the app process runs, notification tap
  opens the chat, notification preferences. Cloud Functions source for
  pushes when the app is closed (`functions/`, not deployed).

**Security and CI**
- Firestore and Storage rules with emulator tests, credential scan,
  formatting, analysis, tests, Firebase configuration validation,
  dependency report, debug APK, release APK when keys exist, signing-key
  generator workflow, logs published to the `ci-logs` branch.

## Required user actions

1. Firebase console: register the Android app `com.aduchat.chat_adunka`,
   enable Email/Password and Phone sign-in, add test phone numbers, create
   Firestore, and publish `firestore.rules`.
2. GitHub secrets: `FIREBASE_API_KEY`, `FIREBASE_APP_ID`,
   `FIREBASE_MESSAGING_SENDER_ID`, `FIREBASE_PROJECT_ID`.
3. Run the **Create signing keys** workflow, then add its 5 secrets and the
   SHA-1/SHA-256 fingerprints in Firebase.
4. Re-run **AduChat CI** on `main` and install the APK on two phones.

Full instructions: [docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md).
