# iPhone, iPad and Mac

The iOS and macOS projects are generated by the **Apple builds** workflow
(branch `apple-scaffold`, then merged). Every push to `main` or `dev` builds
an unsigned iOS app to prove the code compiles for iPhone and iPad.

Bundle id: `com.aduchat.chatAdunka` (Flutter's iOS form of
`com.aduchat.chat_adunka`).

## Steps that need the owner (cannot be done from code)

1. **Register an iOS app in Firebase** (free): Firebase console >
   aduchat-c4ee6 > Project settings > Add app > iOS, bundle id
   `com.aduchat.chatAdunka`. Copy its **App ID** (`1:…:ios:…`) into the
   GitHub secret `FIREBASE_IOS_APP_ID`. It is a public identifier.
2. **Apple Developer Program** membership (USD 99/year, paid: needs your
   approval). Without it Apple does not allow installing on iPhones outside
   Xcode or publishing to TestFlight/App Store.
3. With the membership: create the App Store Connect app record, a
   distribution certificate and provisioning profile, and an App Store
   Connect API key; store them as GitHub secrets
   (`APPLE_CERT_P12_BASE64`, `APPLE_CERT_PASSWORD`,
   `APPLE_PROVISIONING_PROFILE_BASE64`, `ASC_KEY_ID`, `ASC_ISSUER_ID`,
   `ASC_KEY_P8_BASE64`). A signed upload job can then be added.
4. Push notifications on iPhone also need an APNs key uploaded in
   Firebase (Cloud Messaging settings).

Until then iPhone and iPad users can use the web app in Safari and
"Add to Home Screen" (it installs like an app).
